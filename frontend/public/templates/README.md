# Resume Templates

This directory contains preview images for resume templates.

## Template Images

The following template preview images should be added:

- `modern-professional.jpg` - Clean, modern design for corporate roles
- `tech-focused.jpg` - Designed for software developers and engineers  
- `creative-designer.jpg` - Stylish template for creative professionals
- `minimalist-clean.jpg` - Simple, elegant design focusing on content
- `business-executive.jpg` - Professional template for senior positions
- `fresh-graduate.jpg` - Perfect for new graduates and entry-level positions

## Image Specifications

- Format: JPG or PNG
- Dimensions: 400x500px (recommended)
- File size: < 100KB each
- Background: White or light gray
- Content: Mock resume layout showing the template structure
